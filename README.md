# PokéScan

Web app gratuita e open source per scansionare carte Pokémon, vedere il prezzo Cardmarket e tenere la collezione sul tuo telefono. Nessun account, nessun abbonamento, nessun server.

## Come pubblicarla gratis (GitHub Pages)
1. Crea un account GitHub gratuito e un nuovo repository pubblico.
2. Carica `index.html` (e questo README).
3. Settings → Pages → Branch: main → Save.
4. Apri l’indirizzo `https://TUONOME.github.io/NOMEREPO/` da Safari sull’iPhone.
5. Condividi → "Aggiungi a Home" per averla come un’app.

## Note
- Riconoscimento: lettura del testo sul telefono (Tesseract.js). Serve il numero stampato in basso (es. 025/165).
- Dati e prezzi: Pokémon TCG API (prezzi Cardmarket in euro, quando disponibili).
- La collezione è salvata nel browser: se cancelli i dati di Safari, si perde.
- Licenza consigliata: MIT. Carte e immagini Pokémon appartengono ai rispettivi proprietari; progetto non ufficiale.
